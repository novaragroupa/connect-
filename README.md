# نظام Connect لإدارة محل الموبايلات والإكسسوارات

نظام ويب كامل، قاعدة بياناته Google Sheets، وبيتنشر مجانًا على GitHub Pages.

## الفكرة

- **الواجهة (Frontend):** موقع بسيط (HTML/CSS/JS) في مجلد `web/`، بتنزله على GitHub وتشغّله بـ GitHub Pages.
- **الباك اند (Backend):** كود `apps-script/Code.gs` بتحطه جوه Google Sheet واحد (Apps Script)، وهو ده اللي بيقرأ ويكتب في الشيت ويشتغل كـ API للموقع.

كل عملية بيع أو إضافة بتتسجل مباشرة في نفس الشيت، فالمخزون والحسابات بيتحدّثوا لحظيًا مع بعض.

---

## الخطوة 1: تجهيز قاعدة البيانات (Google Sheets)

1. افتح [sheets.google.com](https://sheets.google.com) واعمل ملف Google Sheet جديد وسمّه مثلاً `Connect-Database`.
2. من القائمة اختار **Extensions (إضافات) > Apps Script**.
3. امسح أي كود موجود جوه، وانسخ محتوى ملف `apps-script/Code.gs` كامل والصقه.
4. من أعلى، اختار الدالة `setupSheets` من القائمة المنسدلة، واضغط **Run**. أول مرة هيطلب منك صلاحيات — وافق عليها.
5. رجّع لملف الشيت هتلاقي كل الشيتات اتعملت تلقائي (Users, Maintenance, AccessoryItems... إلخ)، وفيه يوزر مدير جاهز:
   - **Username:** `admin`
   - **Password:** `admin123`
   - غيّرهم فورًا بعد أول دخول من قسم "الموظفين".

## الخطوة 2: نشر الباك اند كـ API

1. في نفس محرر Apps Script، اضغط **Deploy > New deployment**.
2. اختار النوع **Web app**.
3. اضبط:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. اضغط **Deploy**، وانسخ الرابط اللي هيظهرلك (بيبدأ بـ `https://script.google.com/macros/s/.../exec`).

## الخطوة 3: ربط الموقع بالباك اند

افتح ملف `web/config.js` وحط الرابط اللي نسخته بدل `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE`:

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
```

## الخطوة 4: نشر الموقع على GitHub

1. اعمل Repository جديد على GitHub (مثلاً `connect-system`).
2. ارفع محتوى مجلد `web/` بالكامل (index.html, style.css, app.js, config.js) في الـ Repository.
3. من إعدادات الـ Repository: **Settings > Pages**، اختار الفرع `main` والمجلد `/root`، واحفظ.
4. بعد دقيقة أو اتنين هتلاقي رابط الموقع شغال شكله `https://username.github.io/connect-system`.

## هيكل الأقسام في النظام

| القسم | الوظيفة |
|---|---|
| **الرئيسية** | ملخص سريع لمبيعات وأرباح اليوم |
| **الصيانة** | هاردوير/سوفتوير — كشف أعطال أو عطل معروف، مع حساب سعر الجملة والمكسب والإجمالي تلقائي |
| **الإكسسوارات** | أنواع (تقدر تضيف نوع جديد) وجوه كل نوع أصناف، مع بيع مباشر للعميل |
| **الأجهزة** | جديد/مستعمل، مع ضمان أو بدون، وسعر جملة/مكسب/إجمالي |
| **تحويلات الكاش** | سحب أو إيداع مع بيانات العميل |
| **المخزون** | عرض كل الأصناف والكميات المتاحة، بيتحدث تلقائي مع كل عملية بيع |
| **الحسابات** | تقارير يومية/شهرية/سنوية وتقسيم حسب القسم (صيانة/إكسسوارات/أجهزة) |
| **الموظفين** | لمدير النظام فقط — إضافة يوزرات جديدة بصلاحية "مدير النظام" أو "حسابات" |

كل الجداول فيها بحث وفلترة، وكل عملية بيع بتفتحلك نافذة طباعة إيصال (اسم العميل، رقمه، اسم المنتج، اسم الموظف، والإجمالي) — لو عندك طابعة ريسيت (80mm) متوصلة وشغالة كـ طابعة افتراضية في الويندوز/الماك، هتقدر تطبع منها مباشرة من نافذة الطباعة اللي بتفتح تلقائي.

## ملاحظات مهمة

- **الأمان:** الباسوردات متخزنة في الشيت كنص عادي حاليًا لتبسيط النظام — متشاركش رابط الـ Google Sheet نفسه مع حد، وخلي دخول الـ Sheet مقصور عليك أنت بس. لو حابب تأمين أقوى (تشفير باسوردات) قولّي أظبطهولك.
- **الصلاحيات:** فيه نوعين مستخدمين — "مدير النظام" (يشوف كل حاجة بما فيها إدارة الموظفين) و"حسابات" (يشوف كل الأقسام التشغيلية بدون إدارة الموظفين).
- **حدود Google Apps Script:** بيسمح بعدد طلبات محدود في الدقيقة (كافي جدًا لمحل عادي)، ولو الضغط زاد جدًا ممكن نفكر ننقل الداتا بيز لحاجة زي Firebase.
- التطبيق شغال من أي جهاز عنده متصفح وانترنت (كمبيوتر، تابلت، موبايل).

لو حابب أضيف حاجة زيادة (تعديل/حذف العمليات، صلاحيات أدق، تصدير تقارير Excel، ربط مباشر بطابعة ESC/POS بدون نافذة طباعة) قولّي وأظبطها.
